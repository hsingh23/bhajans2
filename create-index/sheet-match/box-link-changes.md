# Box recordings: every song whose accepted recordings changed
`music-meta/match_box.py` accepts a recording for a song only when its title names that song through the shared phonetic key, word for word: the same words (word breaks and a Hindi word-final schwa ignored: "Jay Ma Jay Ma" is "jaya ma jaya ma", "Japo Nam" is "japonam"); or every word a spelling of the same word (same consonant skeleton with vowels identical, or the same written consonants with only the final vowel run or one inserted inner vowel different: Amudam/Amutam, Satguru/Sadguru, tujhe/tuje, namame/namamu, kisiki/kiski); or a long word one consonant apart. An inner vowel change (nalam/nalum), a consonant change (Skanda/Ananda, Raja/Rama, Karunalaye/Karunamayi) or a different word is not the song. Either title may run out first (a track titled with the first words of the song), but the aligned part must be six letters or more with exact-or-spelling words carrying half of it, and the title goes to the song(s) it fits best: "Dam Dam Dum Dum" is dam dam dum dum damaru bole, not dam dam dam dam. A non-language parenthetical in the index name counts as a title of its own. Per changed song: old and new accepted tracks and the verdict for each new track; lost tracks carry the verdict that excluded them.
